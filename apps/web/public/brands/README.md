# Brand marks

Logos of the products on the comparison, use-case and key rotation pages (`/alternatives`, `/for`, `/rotate`) and the platforms on `/download`, shown as one-colour masks (`components/BrandMark.tsx`). They're used only to name each product; the marks belong to their owners.

| --- | --- |
| `1password`, `anthropic`, `apple`, `bitwarden`, `claude`, `cloudflare`, `cloudflare-workers`, `cursor`, `dotenvx` (the .ENV mark), `hashicorp-vault` (Vault), `linux` (Tux), `nextjs`, `nodejs`, `python`, `rails`, `stripe`, `vercel`, `vite` | [Simple Icons](https://simpleicons.org) 16.36.0, CC0 |
| `aws` (light), `codex`, `openai` | [svgl](https://svgl.app) |
| `doppler` | doppler.com's site icon |
| `infisical` | `frontend/public/images/gradientLogo.svg` in [Infisical/infisical](https://github.com/Infisical/infisical) |

Add a file here and set `logo` on the page's entry in `lib/content-pages.ts`.
